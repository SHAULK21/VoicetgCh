# Rozkladka — маленький портативный аналог Punto Switcher

Один `.exe` (~680 КБ, из них ~320 КБ — словари), без установки и без зависимостей.
Живёт в трее, сам ставит себя в автозапуск, исправляет текст, набранный не в той раскладке:
**английский ↔ украинский ↔ русский** — **на лету**, сам, без нажатия клавиш. По горячим клавишам работает и с
любыми другими раскладками Windows (DE, PL, BY, KZ …).

## Исправление на лету

Включено по умолчанию. Набрали `ghbdsn` и пробел — слово само стирается, печатается
`привіт`, и раскладка переключается на украинскую. Так же `руддщ` → `hello`,
`привыт` → `привіт`.

Правый клик по иконке → **«Исправлять на лету»**:

| Режим | Что делает |
|---|---|
| **Всё на украинский** / **Всё на русский** / **Всё на английский** | целевой язык: всё, что набрано не в той раскладке, переводится в этот язык. Настоящие слова других языков (`hello`, `kubectl`) не трогаются |
| **Между всеми языками** | исправляет в любую сторону: англ. ↔ укр. ↔ рус. |
| **Выключено** | только горячие клавиши |

* Исправило зря? Сразу нажмите **Pause** — слово вернётся как было, раскладка тоже, а слово
  запомнится и больше не будет исправляться (`%APPDATA%\Rozkladka\exceptions.txt`).
* **«Не исправлять на лету в «program.exe»»** — выключает авто-режим для последней активной
  программы (для игр, терминалов, IDE).
* Зелёная полоска внизу иконки — авто-режим включён.
* Срабатывает только на пробеле (не на Enter), поэтому пароль, набранный и подтверждённый
  Enter-ом, не меняется.

Как решает: в exe встроены словари 50 000 самых частых слов каждого языка (фильтр Блума)
и буквенные триграммные модели. Слово исправляется, если в набранной раскладке это не слово,
а в другой — слово (или очень похоже на этот язык). Однобуквенные слова перед исправленным
тоже исправляются (`z ns` → `я ти`). На тестовой выборке: ~98% частых слов, набранных не в той
раскладке, исправляются; редкие правильно набранные слова задеваются в ~0,2% случаев.

## Горячие клавиши

| Клавиши | Что делает |
|---|---|
| **Pause** | исправить последнее набранное слово (или отменить авто-исправление). Нажмите ещё раз — следующая раскладка (англ. → укр. → рус. → …) |
| **Двойной Shift** | то же, что Pause (для ноутбуков без Pause; отключается в меню) |
| **Ctrl+Pause** (Break) | исправить всю последнюю фразу |
| **Shift+Pause** | исправить выделенный текст (повторное нажатие — следующая раскладка) |
| **Alt+Pause** | иНВЕРСИЯ рЕГИСТРА — если забыли выключить CapsLock (`пРИВЕТ` → `Привет`) |
| **Alt+Shift+Pause** | регистр по кругу: строчные → ПРОПИСНЫЕ → Каждое Слово |
| **Ctrl+Shift+Pause** | транслитерация `Привіт, світ` ↔ `Pryvit, svit` (официальная укр. система КМУ-2010, для русского — привычная латиница) |

Если ничего не выделено, команды Alt/Ctrl+Shift работают с последним словом.
После конвертации раскладка системы тоже переключается на нужную.

**Трей**: иконка показывает текущую раскладку (EN / UA / RU / …).
Правый клик — меню (вкл/выкл, исправление на лету, исключения программ, двойной Shift,
автозапуск, справка, выход),
двойной клик — включить / выключить.

## Как это работает

* Низкоуровневый хук клавиатуры запоминает **физические клавиши** (scan-коды), которые вы
  нажали в текущем слове. По Pause слово стирается и печатается заново так, как эти же
  клавиши выглядели бы в другой раскладке.
* Раскладки берутся из самой Windows (`ToUnicodeEx` / `VkKeyScanEx`), поэтому учитываются
  ваши реальные варианты (украинская / украинская расширенная и т.д.).
* Первая цель — последняя использованная раскладка другого алфавита (латиница ↔ кириллица):
  `ghbdsn` → `привіт`, `ghbdtn` → `привет`, `руддщ` → `hello`. Если украинская и русская
  обе установлены, сначала берётся та, которой вы пользовались последней; повторное
  нажатие перебирает остальные.
* Выделенный текст копируется через Ctrl+Insert и вставляется через Shift+Insert
  (в терминалах это безопаснее, чем Ctrl+C), а исходное содержимое буфера обмена
  восстанавливается.
* Настройки: `HKCU\Software\Rozkladka`; автозапуск: `HKCU\...\CurrentVersion\Run`
  (без прав администратора). Если перенести exe, путь в автозапуске обновится сам.

## Сборка

Нужен Rust 1.100 (закреплён в `rust-toolchain.toml`).

На Windows:

```bash
cargo build --release
```

Результат: `target\release\rozkladka.exe`.

Кросс-сборка с Linux (нужен `gcc-mingw-w64-x86-64`):

```bash
cargo build --release --target x86_64-pc-windows-gnu
```

Тесты логики конвертации и транслитерации запускаются на любой ОС: `cargo test`.

GitHub Actions (`.github/workflows/rozkladka.yml`) собирает exe на Windows и выкладывает
его как артефакт `rozkladka-exe`: вкладка **Actions** → **Rozkladka (сборка .exe для Windows)** →
последний запуск → раздел **Artifacts**.

Словари и модели (`data/`) пересобираются скриптом
`python3 tools/build_model.py <папка с en_full.txt uk_full.txt ru_full.txt>`.
Исходные частотные списки — [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords)
(OpenSubtitles 2018, данные под CC BY-SA 4.0).

## Ограничения

* Авто-исправление на лету работает для английского, украинского и русского (для них есть
  словари); остальные раскладки — по горячим клавишам.
* Программы, запущенные от администратора, не получают ввод от неадминистративного
  процесса — для них запускайте Rozkladka тоже от администратора.
